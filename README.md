# CMPT310_Project

This project predicts the expected success of a restaurant or cafe location using supervised machine learning. The regression model predicts the Yelp rating for a location, while the classification model predicts whether a location is successful based on whether its rating is at least a 4.0.


The data used includes information about the demographic, geographic, and competitive environment, including:
- `store_name`
- `city`
- `latitude`
- `longitude`
- `neighbourhood_name`
- `median_income`
- `pop_density_sqkm`
- `pct_age_20_39`
- `competitor_count_500m`
- `nearest_transit_distance_m`
- `target_rating`
- `target_is_successful`
